# RoomPing

**家の通信を、測った地点で比べる。** PC とスマートフォン間の LAN HTTP 転送速度・往復応答時間を、間取り上の地点に記録するローカルツールです。

アルファ版 **0.1.0a2** / Python **3.10 以上** / MIT。スマートフォンにはアプリのインストールが不要です。[English](README.en.md)

0.1.0a2は公開前レビュー後の修正版です。Linuxでの今回の検証と、0.1.0a1のmacOS検証記録を分けて [検証記録](docs/VALIDATION.md) に記載しています。

## できること

- PC の参加 URL またはローカル生成 QR からスマートフォンのブラウザで参加。
- PNG/JPEG/WebP の間取り画像、または空白の図に地点を追加。
- 同じ地点を再選択し、「ルーター移動前」「移動後」などの条件別に実測。
- HTTP 往復応答の中央値、PC→スマートフォン／スマートフォン→PC の Mbps を表示。
- 測定した地点だけを表示。未測定の場所への補間やヒートマップはありません。
- 間取り・座標・条件・生のサンプルを JSON で保存し、検証と確認を経て読み込み。CSV も出力。

## 起動

このフォルダーで実行してください。ソースのダウンロードと初回依存インストールにはインターネットが必要です。インストール後の測定は、外部サービスへの接続を必要としません。

```sh
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
# macOS / Linux
source .venv/bin/activate
python -m pip install .
python -m roomping
```

既定は **127.0.0.1:8767**。PC のブラウザで起動時に表示された参加 URL 全体を開きます。URL の `#token=...` も必要です。

スマートフォンから使う場合は、PC の LAN IPv4 アドレスを調べ、明示的に LAN で待ち受けてください。

```sh
# 例のアドレスを実際の PC の LAN IPv4 に置き換える
python -m roomping --host 0.0.0.0 --advertise 192.168.1.20
# または LAN インターフェースだけで待ち受ける
python -m roomping --host 192.168.1.20
```

`--host 0.0.0.0` では `--advertise` が必要です。自動的にインターフェースを選ぶことはありません。PC とスマートフォンを同じ LAN に接続し、OS のファイアウォールでは必要なプライベートネットワークだけに受信を許可してください。PC に表示された URL を開き、「スマートフォンを接続」を展開して QR を読み取ります。停止はターミナルで **Ctrl+C**。

```sh
python -m roomping --help
python -m roomping --version
```

## 測定と比較

1. PC を可能なら有線 LAN に接続します。
2. 間取りを選ぶか、空白の図を使います。画像は PNG/JPEG/WebP、5 MiB 以下・最大 1,600 万画素です。
3. 現在地をタップして地点名を付け、条件名とメモを指定します。
4. 1 回の転送量（1 / 4 / 16 MiB）と繰り返し（1 / 3 回）を選んで測定します。
5. 条件を変えたら同じ丸を選び、再測定します。比較は同じ地点の各条件の最新結果を使います。
6. ページを閉じる前に JSON を保存します。ブラウザ内の記録は自動的に永続化されません。

初期設定は往復応答 7 回、ダウンロードとアップロード各 4 MiB × 3 回（合計 24 MiB）。通信は順番に行い、1 要求 15 秒、測定全体 120 秒で中断します。250 ms 未満の短い転送サンプルには注意表示が付きます。速い LAN では 16 MiB にすると比較しやすくなります。画面を非表示にした場合や通信に失敗した場合は、その回全体を記録しません。

**値の意味:** ブラウザ、HTTP/TCP、PC、LAN を含むアプリケーションの転送性能です。Wi-Fi 電波強度・リンク速度・インターネット回線速度ではありません。「HTTP 往復応答」は ICMP ping ではなく、PC ホストへの HTTP 要求と応答に要した時間です。PC も Wi-Fi の場合、両方の端末の無線区間が影響します。端末・向き・PC 接続・帯域・ルーター設定・他の通信を揃え、メモに残して比較してください。

## 記録とセキュリティ

間取りと結果はブラウザ内で処理します。PC ホストに送るのは容量を限定した測定用バイナリです。CDN、解析サービス、外部フォント、外部測定サーバーは使いません。JSON の読み込みは形式・有限値・ID・参照・座標・件数・画像を検証し、置き換え前に確認欄を表示します。不正なファイルは現在の結果を変更しません。

画像と生サンプルを含む記録全体は、空白を省いたUTF-8 JSONで12 MiB以下です。保存には同じ形式を使い、件数上限より先に容量上限へ達する場合があります。上限を超える追加・編集は既存の記録を保持したまま拒否します。現在のJSONを保存してから、新しい図で測定を続けてください。読み込むファイル自体も12 MiB以下にしてください。

起動ごとの参加トークン、Host／変更要求の Origin 検証、CORS 非開放、要求サイズ・時間・スレッド数の上限を備えます。同時測定は拒否します。中断時の解放に失敗した場合、測定リースは最後の通信から最大 120 秒で失効します。

**信頼できる LAN 専用です。HTTP は暗号化されません。参加 URL はトークンを含むため、信頼できる相手だけに共有してください。ポート転送やインターネットへの公開は行わないでください。** Python 標準 HTTP サーバーを利用するアルファ版です。

CSV は引用符・改行をエスケープし、式として扱われる文字列を無害化します。表計算ソフトによって解釈が異なり、保存・再読込後の動作には差があります。データの完全な保存・再交換には JSON を使ってください。

## 検証状況

macOS で実 HTTP の認証・容量・正確な転送・中断、Node の計測とデータ処理、PC ブラウザでの実測・条件比較・JSON 読込を確認しています。**実スマートフォン、実 Wi-Fi/LAN、Windows、各モバイルブラウザでの実機測定は未検証です。** ブラウザ自動操作で JSON/CSV のダウンロードイベントは捕捉できていません。生成ロジックの自動テストは通っています。詳細は [検証記録](docs/VALIDATION.md)。

開発用テスト:

```sh
python -m pip install -e .
python -m unittest discover -s tests -v
node --test tests/*.test.mjs
python -m pip install build
python -m build
```

JavaScript テストには Node.js 22 以上を推奨します。HTTP テストはループバックの一時ポートを使います。[設計](docs/DESIGN.md) / [公開手順](docs/PUBLISHING.md) / [引継ぎ](docs/HANDOFF.md)。
